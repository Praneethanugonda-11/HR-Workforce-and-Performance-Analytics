# HR Workforce and Performance Analytics

## Project Overview

This project focuses on analyzing HR data to understand
employee distribution, salary and compensation,
department performance, workforce demographics,
and hiring trends.

## Project Objectives

- Analyze employee information.
- Understand workforce distribution by department and location.
- Analyze salary and compensation.
- Examine employee performance ratings.
- Explore hiring trends.
- Present results using Power BI dashboards.

## Tools and Technologies

- Python
- Pandas
- SQL
- Power BI

## Datasets

- Employee Information
- Employee Salary
- Department Information
- Job Roles

## Project Workflow

1. Load and inspect the datasets.
2. Check data quality and missing values.
3. Prepare and combine relevant datasets.
4. Perform HR data analysis.
5. Create Power BI dashboards.
6. Document findings and limitations.

## Power BI Dashboard

The dashboard covers:

- HR Workforce Overview
- Department Performance
- Salary and Compensation Analysis
- Performance Analysis
- Workforce Demographics
- Hiring and Workforce Trends
